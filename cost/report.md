## Formulas

- Measured: `item_cost = billed_units x usd_per_million / 1,000,000` at the tier the provider reported; items are mutually exclusive (input_uncached = input - cached - cache_write; input_cached; input_cache_write; output including reasoning). Subscription (`claude -p`) items cost $0 billed; their API-equivalent uses the reported model's API row.
- Projected stage cost = projected reviews (or fixed calls for group/memo) x measured billed cost per unique review (or per call), which already contains the measured retries, cache hits and tier; the base scenario adds no extra retries when inputs are measured, the conservative one multiplies by (1 + transient + invalid-output retry rates) and by a token multiplier. Fallback rates are the measured share of reviews routed, capped by the declared maxima.
- Projected seconds = requests / min(workers / mean latency, provider requests-per-minute limit / 60), summed over stages, plus code stages per 1,000 rows.
- Doubling every API rate doubles billed totals; local compute and measured times do not change. Changing projected counts never changes the measured sections.
